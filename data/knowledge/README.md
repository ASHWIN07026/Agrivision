# data/knowledge

Agricultural domain knowledge documents used for contextual responses.

## Contents

| File | Description |
|---|---|
| `disease_treatments.json` | JSON map of disease name → treatment recommendation |
| `crop_seasons.json` | Crop → best sowing & harvest months in India |
| `soil_types.json` | Soil type descriptions and suitability per crop |

These files are read by the backend services to enrich prediction responses.
